LIS 检验工作台功能与操作手册

版本：0.1（基于当前中国版界面） 更新日期：2026-09-21 适用对象：检验科接收人员、检验人员、审核人员、报告人员、质量负责人、系统管理员

1. 先理解这套系统在做什么

这套 LIS 按一份检验申请的生命周期组织工作：

建立申请 → 采集/签收标本 → 打印并核对标签 → 标本验收
        → 结果录入 → 结果审核 → 报告签发/查询
        ↘ 异常进入质量管理，接口与基础资料由管理中心维护

每个岗位只处理自己有权限的环节。左侧菜单是工作入口，页面中的状态、筛选和步骤条说明当前任务走到哪里。菜单分组可以同时展开；点击分组标题只负责展开或收起，不会改变其他分组。

2. 第一次登录后的 10 分钟上手

  1. 确认账号和实验室。 登录后查看右上角账号、当前实验室或专业组。菜单少于本手册属于权限差异，不代表功能丢失。
  2. 先看“工作台”。 工作台显示今日待办、异常和各环节数量，可点击卡片进入对应队列。
  3. 用一条测试申请跑通流程。 进入“申请与标本”，新建申请，依次完成“新建申请、采集签收、贴签上架、标本验收”。
  4. 在“检验”录入测试结果。 找到刚验收的标本，录入结果并保存。
  5. 在“审核与报告”完成审核。 审核结果，确认患者、项目、结果、单位和参考范围，再进入报告查询或签发。
  6. 遇到异常不要绕过。 标本拒收、质控失控、结果退回等情况进入“质量管理”留痕。

建议培训时使用明确标记的测试患者和测试标本。正式上线前不要用真实患者数据验证尚未接通的接口。

3. 左侧六个入口

4. 日常业务闭环

4.1 建立检验申请

入口：申请与标本 → 申请列表 → 新建申请。

操作顺序：

  1. 先搜索患者，优先复用已有患者档案，避免重复建档。
  2. 核对患者姓名、性别、出生日期、证件或患者唯一编号。
  3. 选择送检机构、科室、医生和优先级。
  4. 选择标本类型和检验项目；能从下拉框选择的内容不手工输入。
  5. 保存申请。系统生成实验室编号后，才表示申请已经建立。

注意：急诊、定时采集和普通申请应选择正确优先级。发现患者重复时不要继续建立第二份档案，应交由有权限人员处理患者合并。

4.2 采集或签收标本

入口：申请的第二步 采集签收，也可在申请列表扫描条码后继续。

操作顺序：

  1. 扫描或输入实验室编号。
  2. 核对患者和申请项目。
  3. 对院内采集标本登记采集信息；对外送标本登记签收信息。
  4. 核对标本类型、容器、数量、采集/签收时间和人员。
  5. 保存后进入贴签步骤。

标本不符合要求时，不要直接标记完成。记录拒收、重采或不符合事件，并填写原因。

4.3 打印标签与上架

入口：申请的第三步 贴签上架。

  1. 选择对应标本管和标签预设。
  2. 预览标签，核对患者标识、实验室编号、标本类型和条码。
  3. 打印并贴在正确容器上，避免遮挡液面和原有关键标识。
  4. 需要位置管理时选择存储位置；现场暂不管理位置时，按本机构规则选择跳过。

打印失败时先检查浏览器打印窗口、打印机选择和标签尺寸。不要连续重复点击打印，以免产生重复标签。

4.4 标本验收

入口：申请的第四步 标本验收。

  1. 核对申请、患者、标本、标签和检验项目是否一致。
  2. 检查标本量、容器、溶血/凝块/污染等情况。
  3. 合格则确认进入检验；不合格则选择问题类型和处置。
  4. 完成后，申请从接收环节进入检验队列。

步骤条后续环节不可点击时，说明前序步骤尚未完成。返回前一步补齐必填项后再继续。

4.5 结果录入

入口：检验 → 结果录入工作台。

  1. 待录入队列会自动加载。可按实验室编号、状态、日期或专业组筛选。
  2. 先选择标本，再逐项录入结果。
  3. 核对单位、参考范围、异常标志和仪器原始结果。
  4. 保存当前结果。保存成功只表示“完成结果录入”，尚未审核和签发。
  5. 页面存在未保存输入时先处理，再进入审核。

关键规则：

  • “本页输入未保存”表示数据仍在浏览器页面中，不能当作服务器已经保存。
  • 保存结果未知或超时时不要重复提交；先刷新并核对服务器记录。
  • 结果不可编辑时，检查标本状态、项目配置、权限和是否已被审核。
  • 质控拒绝级失控会拦截相关仪器结果放行，应先处理质控问题。

4.6 结果审核

入口：审核与报告 → 审核工作台。

可按专业组、申请单、申请单范围或检验日期查询待审核结果。

审核顺序：

  1. 核对患者和标本身份。
  2. 查看结果、单位、参考范围、异常标志和历史结果。
  3. 必要时查看原始值、分析版本或不符合记录。
  4. 正确的结果选择接受；需修改的结果选择退回并填写原因。
  5. 批量操作前再次核对选中范围，再提交审核。

审核人员不应替代检验人员直接修改原始结果。危急值、质控失控或身份不清的记录应先按本机构制度处置。

4.7 报告查询、签发与打印

入口：审核与报告 → 报告工作台。

报告可按实验室编号、患者、送检机构和日期查询。正式报告流程包括：

  1. 选择检验申请和报告分组。
  2. 建立或选择报告文档版本。
  3. 冻结报告内容。
  4. 核对患者身份、结果、单位、参考范围和预览 PDF。
  5. 输入当前账号密码完成签名和签发。
  6. 打印时登记打印记录；更正或作废必须填写原因。

“预览”不是正式报告。只有已签发版本可作为当前正式报告；更正版签发后，原版本应保留为历史原件。

5. 工作台和常用操作

5.1 工作台

工作台用于判断“今天先做什么”。优先处理急诊、超时、待审核、异常和接口失败任务。数字卡片表示当前队列数量，点击后进入对应页面。

5.2 搜索和扫描

  • 顶部搜索用于跨页面查找常用对象。
  • 条码输入框适合扫描实验室编号；扫描枪通常等同于键盘输入并回车。
  • 列表内搜索只过滤当前业务范围。没有结果时先清除筛选，再检查日期和状态。

5.3 列表返回

从列表进入详情后使用页面上的“返回列表”，系统会尽量保留之前的搜索、筛选和页码。浏览器直接后退可能丢失未保存输入。

5.4 菜单展开

左侧各分组可以独立展开和收起，可同时保留多个分组。当前页面所属分组会自动展开。图钉用于固定侧栏；小屏幕下选择页面后侧栏会自动收起。

6. 质量管理

6.1 不符合项

用于记录标本拒收、申请错误、结果问题、流程偏差等事件。一般流程为：登记事件 → 分派/调查 → 纠正措施 → 复核关闭。记录应包含发生时间、对象、原因、处理人和证据。

6.2 室内质控

质控工作台按仪器和项目查看状态、控制图、告警和活动记录。拒绝级规则触发后，相关患者结果可能被阻止放行。先确认控制品批号、靶值、仪器状态和规则，再决定重测、校准或解除。

6.3 告警

告警需要明确确认人和处置结果。确认告警只表示已知悉，完成纠正并验证有效后才能关闭。

7. 管理中心

管理中心按业务领域组织配置。可在首页搜索配置名称，不需要记住旧菜单路径。

7.1 检验目录

  • 检验主数据：项目目录、标本类型、组合、专业组、单位、方法、结果选择列表。
  • 规则管理：反射检验、计算项目、批量项目调整。

建议顺序：先建立单位/方法/标本类型和专业组，再建立检验项目，最后配置组合、规则和可开单范围。

7.2 机构与人员

  • 用户：账号、角色、启停状态。
  • 机构：医院、科室、送检单位等组织资料。
  • 医务人员：申请医生或相关人员资料。

账号应按人分配，禁止多人共用。岗位变化时同步调整角色，不应只隐藏菜单而保留不必要权限。

7.3 流程与报告配置

包含站点信息、品牌、申请录入、患者、工作单、实验室编号、标签预设、结果录入、审核、打印报告、结果发送和检验通知配置。

变更编号、标签、审核或报告规则前，应记录变更原因并在测试环境用完整流程验证。

7.4 仪器与接口

  • 仪器管理：仪器资料、连接方式和状态。
  • 仪器项目映射：将仪器项目代码映射到 LIS 检验项目。
  • 外部连接：HIS/EMR 等连接配置。
  • 数据发送监控：查看成功、待处理、失败和重试记录。
  • 室内质控工作台：查看与仪器相关的质控状态。

接口失败时先查看发送监控的时间、目标、状态和错误信息，再决定重试。未知结果时不要连续重发。

7.5 系统与安全

包含日志级别、搜索索引、数据库清理、语言、翻译、插件和系统参数。数据库清理、插件及关键系统参数属于高风险操作，应由指定管理员执行，并在操作前完成备份和变更记录。

7.6 数据维护与上线准备

主数据编码、附加申请配置和上线准备集中在此。上线准备页目前用于保存本机配置草稿和模拟验证，覆盖 HIS、仪器、打印、时效/审核规则及检查清单。

9. 常见问题

看不到某个菜单

先确认登录账号、角色和当前实验室。菜单按后端授权显示；管理员修改角色后，退出并重新登录再检查。

页面提示加载失败

先点击“重新加载页面”。仍失败时记录页面名称、发生时间、实验室编号和操作步骤，交给管理员查看服务状态。不要反复提交写入操作。

保存后不确定是否成功

返回列表或刷新读取服务器当前状态。若页面明确提示“结果尚未确认”，不要重复保存、签发、打印或重试接口。

扫描条码没有反应

点击条码输入框后再扫描，确认扫描枪会发送回车；也可手工输入实验室编号验证。再检查条码内容是否与系统编号格式一致。

打印内容或尺寸不对

检查标签预设、浏览器打印缩放、纸张尺寸和打印机。先用测试标签校准，不要直接用患者正式标签试印。

结果不能审核或报告不能签发

检查结果是否保存、当前账号权限、质控拦截、报告分组和患者/标本信息是否完整。退回记录必须写明原因。

10. 建议的岗位日清单

接收/采样人员

  • 清理采集待办、标签待办和验收待办。
  • 处理拒收、重采和身份不符记录。
  • 核对当天未完成申请。

检验人员

  • 处理本专业组待录入结果。
  • 检查仪器导入失败和本页未保存输入。
  • 交班前确认急诊及超时任务。

审核/报告人员

  • 清理待审核和退回队列。
  • 核对危急值、质控拦截和异常结果。
  • 检查待签发、待打印及更正报告。

质量负责人

  • 查看质控告警和不符合项。
  • 跟踪纠正措施和未关闭事件。
  • 抽查审计记录及关键配置变更。

系统管理员

  • 查看接口失败、服务异常和数据发送积压。
  • 管理账号、角色和主数据变更。
  • 按制度检查备份、日志和上线检查项。

11. 上线前必须补齐的医院资料

  1. HIS/EMR 接口规范、字段字典、认证方式和测试地址。
  2. 仪器清单、通讯协议、驱动方式和项目代码表。
  3. 报告样张、签章规则、报告分组、更正/作废制度。
  4. 标签尺寸、条码规则、打印机型号和部署位置。
  5. 岗位角色、审核层级、危急值和质控放行规则。
  6. 实验室编号、专业组、标本、项目、单位和参考范围主数据。
  7. UAT 场景、验收人和上线/回退方案。

本手册描述当前软件的工作方式。医院制度与本手册不一致时，应先完成配置、开发和验证，再更新手册并培训使用人员。
