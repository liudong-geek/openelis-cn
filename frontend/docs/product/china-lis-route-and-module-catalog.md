# 中国版 LIS 路由与模块清单

状态：UX01 基线（2026-09-18）  
依据：`src/App.jsx`、服务端授权菜单、当前中国版导航适配器

## 结论

`App.jsx` 当前注册 124 个路由入口（其中 5 个是 `/order` 内的动态子路由，另含兜底路由）。这些入口来自 OpenELIS 的通用版、专科扩展、科研项目和国内版新增功能，不能全部进入日常导航。

中国版将产品范围分成三层：

1. **标准核心**：始终可用，并按权限显示在六个一级入口中。
2. **可选模块**：代码和路由保留，医院启用后才进入导航。
3. **兼容入口**：保留旧链接或内部跳转能力，不进入主导航。

## 六个一级入口

| 顺序 | 一级入口   | 日常任务                                                   | 页面组织原则                                   |
| ---- | ---------- | ---------------------------------------------------------- | ---------------------------------------------- |
| 01   | 工作台     | 待办、异常、快捷扫描、最近处理                             | 直接进入，不展开                               |
| 02   | 申请与标本 | 申请列表、采集、贴签、签收、患者档案                       | 一个平面任务列表；状态和视图放进页面筛选       |
| 03   | 检验       | 工作单、结果录入、仪器结果                                 | 工作单类型放进页内标签和筛选                   |
| 04   | 审核与报告 | 结果审核、报告查询、打印                                   | 审核方式和报告类型放进页内标签                 |
| 05   | 质量管理   | 不符合项、质控、纠正措施、告警                             | 质量总览进入后再按业务卡片处理                 |
| 06   | 管理中心   | 检验目录、人员机构、流程报告、仪器接口、系统安全、数据维护 | 主导航只进入管理中心；详细配置由搜索和卡片承载 |

所有一级入口继续受服务端角色权限控制。导航重组不提升权限，也不补回服务端未授权的菜单。

## 可选模块配置

`src/config.json` 中的 `optionalModules` 是部署级开关，默认全部关闭。模块只有同时满足以下条件才显示：

1. 部署配置已启用；
2. 服务端返回了该菜单；
3. 当前账号具有对应角色权限。

因此开关不会绕过后端授权。专科模块启用后仍归入对应的六个产品入口，不恢复“更多功能”式的杂项菜单。

## 后续退役规则

- 兼容路由在医院真实接口和 UAT 完成前保留，避免旧书签和外部链接失效。
- 每个兼容路由必须指定新入口、使用量和退役版本，确认无人使用后才能删除。
- 新功能不得新增一级菜单；优先使用页面标签、筛选、抽屉或管理中心卡片。
- 单个角色可见的一级入口按实际权限连续编号，避免出现 01、04、06 这类断号。
