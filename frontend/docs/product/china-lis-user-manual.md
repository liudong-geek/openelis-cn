# LIS 检验工作台功能与操作手册

版本：0.3（适配当前 `develop` 中国版界面）

更新日期：2026-09-27

适用对象：申请与标本接收人员、检验技师、结果审核人员、报告发布人员、质量负责人、系统管理员和审计人员

> 本手册说明当前本地版本的真实工作方式。菜单会随岗位权限变化；医院尚未提供的接口、仪器、报告样张、标签规格、危急值和质控规则，必须在现场资料齐全后配置并验收。

## 1. 先看懂 LIS 的完整流程

LIS 围绕“申请—标本—检验任务—结果—报告”组织工作。一份申请可以对应一管，也可以按标本类型拆成多管。

```text
HIS/电子申请 ─┐
              ├→ 申请登记 → 生成申请号与管码 → 采集/签收 → 逐管验收
LIS 手工申请 ─┘                                      │
                                  合格管 → 结果录入 → 结果审核 → 报告发布/查询/打印
                                  拒收管 → 记录原因 → 关联补采 ────────────┘
```

需要记住四个概念：

- **申请号**：标识一份检验申请，一份申请可包含多个项目和多管标本。
- **管码**：标识一支实际标本管。多管申请的每支管都有独立管码。
- **检验任务**：由申请项目和标本管共同产生，只有已验收合格的管可以继续检验。
- **逐管验收**：同一申请内，一管合格、一管拒收时分别处理；合格管继续，拒收管进入补采，不把整单一起阻断。

页面状态比菜单位置更重要。每次操作后都要确认状态已变化，再进入下一环节；出现“保存结果未知”时先查询服务器状态，不要重复提交。

## 2. 第一次登录后的 10 分钟上手

建议培训时使用明确标记的测试患者和测试标本。正式联调前不要录入真实患者资料。

1. **确认账号和岗位。** 登录后查看右上角账号。菜单少于本手册通常是岗位权限差异，不代表功能丢失。
2. **打开工作台。** 查看今日待接收、待录入、待审核和待打印数量；点击待办可进入对应队列。
3. **建立一份单管测试申请。** 进入“申请与标本 → 申请列表 → 新建申请”，选择患者、送检机构、标本类型和检验项目后保存。
4. **完成采集和标签。** 在申请流程中确认管码，登记采集；需要时预览并打印标签。演示环境可选择“仅采集，稍后签收”。
5. **完成签收和验收。** 进入“申请与标本 → 标本处理”，扫描管码，核对患者、申请、标本类型和项目，先签收再验收。
6. **录入结果。** 进入“检验 → 待录入结果”，找到刚验收的标本，填写并保存结果。
7. **审核结果。** 使用审核岗位进入“审核与报告 → 审核工作台”，核对后通过；有问题则退回并填写原因。
8. **查询报告。** 进入“审核与报告 → 患者检验报告”，按患者或实验室编号查询已审核结果并预览报告。

如果第 5 步之后在待录入队列找不到任务，优先检查：管码是否正确、标本是否已验收、项目是否分配到当前专业组、当前账号是否有该专业组权限。

## 3. 七个一级菜单

| 一级菜单   | 主要使用岗位                     | 主要任务                                                 | 典型输出                    |
| ---------- | -------------------------------- | -------------------------------------------------------- | --------------------------- |
| 工作台     | 所有岗位                         | 查看今日待办、异常和快捷入口                             | 进入对应业务队列            |
| 申请与标本 | 接收、采样人员                   | 电子申请接收、手工建单、采集、条码、签收、逐管验收       | 合格检验任务或拒收/补采记录 |
| 检验       | 检验技师、仪器数据人员           | 待录入结果、外送检验、检验工作单                         | 已保存的检验结果            |
| 审核与报告 | 审核、报告人员                   | 结果审核、退回、报告查询、统计                           | 审核结论和报告              |
| 质量管理   | 质量负责人                       | 不符合项、质量预警和处理闭环                             | 处置记录和关闭结论          |
| 基础配置   | 系统管理员                       | 检验主数据、规则、机构人员、流程报告、仪器接口、数据字典 | 可供业务选择的配置          |
| 系统管理   | 账号管理员、系统管理员、审计人员 | 用户权限、运行参数、语言、日志和审计                     | 账号权限及运维记录          |

左侧菜单分组可以同时展开。一级菜单负责跨业务模块导航；页面内页签只用于同一任务的视图切换。常规搜索默认保持简洁，更多条件通过“高级搜索”展开。

## 4. 默认岗位权限

入口：**系统管理 → 用户管理 → 新建/编辑用户 → 默认岗位模板**。

选择模板后还要选择适用专业组并保存。模板是建议起点，医院可按实际岗位微调；菜单可见性和后端操作权限会同时生效。

| 默认岗位模板       | 默认可见业务域               | 允许的主要操作                               | 不应承担的操作             |
| ------------------ | ---------------------------- | -------------------------------------------- | -------------------------- |
| 申请与标本接收员   | 工作台、申请与标本、质量管理 | 患者建档、申请接收、采集签收、条码和不符合项 | 结果录入、结果审核         |
| 检验技师           | 工作台、检验                 | 指定专业组工作单和结果录入                   | 审核自己的结果、发布报告   |
| 结果审核员         | 工作台、审核与报告、质量管理 | 指定专业组结果复核、退回和批准               | 同批原始结果录入、系统配置 |
| 报告发布员         | 工作台、审核与报告           | 查询、生成和交付已审核报告                   | 修改原始检验结果           |
| 质量负责人（常规） | 工作台、质量管理、审核与报告 | 不符合项、审核追踪、质量报表和审计查看       | 日常结果录入、仪器质控配置 |
| 仪器数据操作员     | 工作台、检验、系统管理       | 仪器结果导入及指定专业组结果录入             | 结果审核、报告发布         |
| 用户账号管理员     | 工作台、系统管理             | 新增/停用账号、分配岗位权限                  | 检验业务操作               |
| 系统管理员         | 工作台、基础配置、系统管理   | 主数据、接口和系统运行参数                   | 日常结果录入或审核         |
| 审计查看员         | 工作台、审计入口             | 只读查看审计记录                             | 修改患者、申请、结果或配置 |

系统会提示同一专业组同时拥有“结果录入”和“结果审核”的职责冲突。人员不足时如需兼岗，应由医院建立补偿性复核制度，不能只靠隐藏菜单代替权限控制。

## 5. 申请与标本

### 5.1 接收电子申请或手工建单

- **电子申请**：进入“待接收电子申请”，核对 HIS/EMR 传入的患者、项目、送检科室和医生后接收。
- **LIS 手工申请**：进入“申请列表 → 新建申请”，用于单机运行、模拟演示或医院允许的补录场景。
- **批量申请录入**：适合体检或同批标本；正式使用前应先确认批量编号和标签规则。

手工建单顺序：

1. 搜索并选择已有患者；确认没有档案后再新建，避免重复患者。
2. 核对姓名、性别、出生日期、证件或患者唯一编号。
3. 选择送检机构、科室/病区、申请医生和优先级。
4. 选择标本类型、组合项目或单项检验。
5. 核对系统分配的标本管，保存申请并记录申请号。

申请号默认由系统首次保存时生成。只有接收外部系统已有编号时才录入外部编号。

### 5.2 单管和多管申请

**单管**指申请中的项目都可由同一支标本完成。**多管**指同一申请因标本类型、容器或检验要求不同，需要生成两支或更多实际标本管。

当前系统按“标本类型—检验项目”配置自动拆管。例如一份申请同时包含血清生化和全血血常规时，应形成血清管和全血管，各有独立管码。

操作人员不需要手工决定底层关联，只需在保存前核对：

- 每个项目是否归到正确标本类型；
- 管数是否符合当前申请项目；
- 每支管的条码、标本类型和项目是否一致；
- 后续采集、签收、验收和拒收是否作用于当前管。

### 5.3 采集和标签

1. 打开申请并进入采集步骤。
2. 逐管核对患者、标本类型、管码和项目。
3. 登记采集时间和采集人员；暂不签收时选择“仅采集，稍后签收”。
4. 预览标签，核对患者标识、管码、标本类型和条码。
5. 打印后贴在正确容器上，避免遮挡液面和原有关键标识。

打印失败时先检查浏览器打印窗口、打印机、纸张和标签预设。不要连续点击打印，以免产生重复标签。

### 5.4 扫码签收和逐管验收

入口：**申请与标本 → 标本处理**。

1. 扫描或输入管码，系统定位申请、患者和当前管。
2. 核对患者身份、标本类型、容器、采集时间和检验项目。
3. 未签收的管先完成签收。
4. 合格管选择验收，进入结果录入队列。
5. 不合格管选择拒收原因并提交，系统保留拒收记录。
6. 需要重新采集时建立关联补采申请，新管使用新管码继续流程。

同一申请中的各管独立处理。一管拒收不会自动撤销另一支已验收合格管；已验收管的项目可以继续检验。

### 5.5 常见标本异常

标本量不足、容器错误、凝块、溶血、污染、身份不清等原因必须按医院制度配置。软件提供拒收、原因记录和补采关联能力；哪些情形必须拒收、是否允许让步接收，属于医院待确认规则。

## 6. 检验

### 6.1 待录入结果

入口：**检验 → 待录入结果**。

1. 默认加载当前账号可见的待处理队列；可按实验室编号、专业组、日期和状态筛选。
2. 选择左侧标本，核对患者、管码和项目。
3. 逐项填写结果，核对单位、参考范围、异常标志和仪器原始值。
4. 保存当前结果。保存成功表示录入完成，尚未完成审核和报告发布。
5. 结果不可编辑时点击“受限说明”，先处理标本未验收、项目拒收、质控阻断或权限不足等原因。

顶部数量是检验任务数，左侧数量是标本记录数，两者口径不同。加载失败或状态未知时不要把空白当成零。

### 6.2 外送检验

外送页面默认先显示常用患者/实验室编号查询，出生日期、性别等放在高级搜索中。查询后核对外送机构、项目、送出时间和回传结果。

医院需要提供外送机构、项目映射、报告回传和责任边界后，才能作为正式外送流程验收。

### 6.3 检验工作单

检验工作单用于从同一个待检验任务集合中按检验项目、组合项目、专业组或优先级分类筛选并打印。分类是筛选条件，不是四套独立业务流程。

打印前核对专业组、筛选条件、项目总数和异常标记。工作单只辅助台面作业，不能代替系统中的标本状态和结果记录。

## 7. 审核与报告

### 7.1 结果审核

入口：**审核与报告 → 审核工作台**。

1. 按专业组、申请单或检验日期加载待审核队列。
2. 核对患者、标本、结果、单位、参考范围、异常标志和历史结果。
3. 正确结果选择通过；需修改的结果选择退回并填写原因。
4. 批量通过前再次核对选中范围，再提交审核。

统计显示整次查询的任务数，不等于当前页行数。质控受阻、已签发遗留或权限不足的记录可能只读，应按页面提示处理。

审核人员不应替代检验技师直接改写原始结果。危急值、质控失控或身份不清的处置方式必须按医院制度配置。

### 7.2 报告查询、发布与打印

入口：**审核与报告 → 患者检验报告**。

1. 按实验室编号、患者、送检机构或日期查询。
2. 选择已审核申请，核对报告分组和报告内容。
3. 预览报告，确认患者、结果、单位和参考范围。
4. 由有权限人员发布/签发报告。
5. 打印时登记打印记录。

预览不等于正式报告。报告样式、电子签章、审核层级、更正/作废流程和临床发送方式，仍需医院资料和现场验收。当前版本不要把报告更正当作已经完成的生产闭环。

### 7.3 业务统计

检验工作量、项目汇总、外送结果、不符合项和审核超时等统计共用一套分类查询方式：先选择统计类型，再在同页设置专业组、优先级、日期等条件。统计口径应在正式使用前由医院确认。

## 8. 质量管理

### 8.1 不符合项

用于记录标本拒收、申请错误、结果问题和流程偏差。默认直接显示台账列表，常用搜索在列表上方；状态、类别、严重度等更多条件通过高级搜索展开。

一般流程：登记事件 → 分派/调查 → 纠正措施 → 复核关闭。记录应包含发生时间、对象、原因、处理人和证据。

### 8.2 质量预警

质量预警按规则显示待处理风险。确认告警只表示已知悉；完成处置并验证有效后才能关闭。

仪器质控规则、危急值范围和放行条件属于医院制度。系统管理员负责配置，质量负责人负责按制度处置和追踪。

## 9. 基础配置

基础配置按业务领域组织，不再使用顶部功能页签。先从左侧一级菜单进入，再选择对应配置组。

| 配置组             | 主要内容                                       | 推荐配置顺序                   |
| ------------------ | ---------------------------------------------- | ------------------------------ |
| 检验主数据         | 检验项目、标本类型、组合、专业组、单位、方法   | 先字典和标本类型，再项目和组合 |
| 规则管理           | 反射检验、计算项目、参考范围、结果规则         | 主数据稳定后配置并验证         |
| 机构与人员         | 医院、科室/病区、送检机构、申请医生            | 先组织，再人员和联系方式       |
| 流程与报告配置     | 申请、编号、条码、标签、结果、审核、报告和通知 | 按一条完整测试申请逐项验证     |
| 仪器与接口配置     | 仪器、项目映射、外部连接、发送监控             | 取得协议和测试地址后联调       |
| 主数据编码与有效期 | 外部编码、启停状态和生效范围                   | 与 HIS/仪器代码表对照维护      |
| 附加申请配置       | 补充申请字段和专用业务资料                     | 医院确认后启用                 |
| 上线准备           | 本机配置草稿和检查清单                         | 仅作准备记录，不代替验收       |

### 9.1 多管规则怎么配置

1. 在“基础配置 → 检验主数据”维护标本类型。
2. 为每个检验项目关联正确的标本类型。
3. 在组合项目中核对各子项目的标本类型，不要强行合并不同标本要求。
4. 使用一份测试申请同时选择两种标本类型的项目，确认生成多支管及独立管码。
5. 分别验收、拒收和补采，确认只有对应管的任务受影响。

容器帽色、采血顺序、最小采血量、分杯和运输温度尚不能由项目团队代替医院决定。取得院方规则后再增加配置和验收场景。

## 10. 系统管理

### 10.1 用户和权限

账号按人分配，禁止多人共用。新增用户时先应用默认岗位模板，再选择专业组并核对职责边界。岗位变化、离职或轮岗时及时调整或停用账号。

### 10.2 操作日志

操作日志默认直接显示最近记录。日期、业务对象、操作类型、用户和业务编号等条件放在可展开的高级搜索中。先缩小日期范围，再按业务编号追溯；导出只用于授权的审计用途。

### 10.3 系统参数和语言

系统参数、语言、翻译、日志级别、搜索索引和数据库维护由系统管理员操作。删除、停用、数据库清理等高风险动作会显示确认框；应核对对象和影响后再确认。

## 11. 页面操作规则

### 11.1 搜索

- 列表默认展示可查看的数据，并提供一行常用搜索。
- “高级搜索”展开日期、状态、类别、专业组等低频条件。
- 无结果时先清除筛选，再检查日期、状态、专业组和权限。
- 条码框适合扫描枪；扫描枪通常等同于键盘输入并回车。

### 11.2 返回和未保存内容

从列表进入详情后优先使用页面中的“返回列表”，以保留搜索、筛选和页码。离开有未保存内容的页面时，应先保存或明确放弃；不要用刷新来判断保存是否成功。

### 11.3 弹窗

弹窗只用于不离开当前任务即可完成的短操作，例如选择患者、查看详情、填写拒收原因或确认删除。较长的申请、配置和多步骤流程使用完整页面。

危险操作的弹窗会明确显示对象、影响和红色确认按钮。关闭或取消不会执行操作。

### 11.4 页面加载失败

先点击“重新加载页面”。仍失败时记录页面名称、时间、申请号或管码及操作步骤，交给管理员查看服务状态。写操作失败时不要连续点击。

## 12. 常见问题

### 看不到某个菜单

确认账号岗位和专业组。管理员修改权限后退出并重新登录。若岗位模板包含菜单但操作仍被拒绝，应检查后端角色是否已保存。

### 新建申请时没有可选标本类型或项目

检查检验项目是否启用、是否关联标本类型和专业组、送检机构是否有开单范围。由系统管理员修复主数据后重新打开申请。

### 一支管合格、另一支管不合格，怎么办

分别处理每支管。合格管验收后继续检验；不合格管记录拒收原因并建立关联补采。不要撤销整份申请，也不要把补采管复用旧管码。

### 扫描管码没有反应

先点击管码输入框再扫描，确认扫描枪会发送回车；也可手工输入管码验证。再检查标签内容与系统管码是否一致。

### 保存后不确定是否成功

保留当前页面，按页面提示查询服务器状态。未确认前不要重复保存、审核、发布、打印或重发接口。

### 结果不能录入、审核或发布

依次检查标本是否验收、项目是否拒收、当前专业组权限、结果是否保存、质控是否阻断、审核是否完成。页面“受限说明”会显示可处理原因。

### 打印内容或尺寸不对

检查标签/报告预设、浏览器缩放、纸张和打印机。使用测试标签和测试报告校准，不能直接拿患者正式标签反复试印。

## 13. 岗位日清单

### 申请与标本接收人员

- 清理待接收电子申请、采集/签收和验收待办。
- 处理拒收、补采和身份不符记录。
- 核对当天未完成申请及未处理标本管。

### 检验技师

- 清理本专业组待录入结果和退回结果。
- 检查仪器导入失败、受限任务和未保存输入。
- 交班前确认急诊及超时任务。

### 审核和报告人员

- 清理待审核和退回队列。
- 核对异常结果、质控阻断和危急值处置。
- 检查待发布、待打印和报告异常。

### 质量负责人

- 查看质量预警和不符合项。
- 跟踪纠正措施和未关闭事件。
- 抽查审计记录及关键配置变更。

### 系统和账号管理员

- 查看接口失败、服务异常和发送积压。
- 管理账号、权限和主数据变更。
- 按制度检查备份、日志和上线检查项。
