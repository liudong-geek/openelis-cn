# LIS 检验工作台功能与操作手册

版本：0.6.3（候选版）

更新日期：2026-10-20

适用版本：六批优化演示版及仪器质控异常处理修复候选版

文档性质：岗位操作手册

适用对象：申请与标本接收人员、检验技师、结果审核人员、报告发布人员、质量负责人、账号管理员、系统管理员和审计人员

本手册记录中国版检验工作台的操作入口、资料核对和状态反馈，包含六批优化后的管理入口、编辑弹窗和返回操作。演示范围与医院待验收事项列于第14节。

## 1. LIS 业务流程

```text
患者档案 → 检验申请 → 标本管与检验项目
                       ↓
               采集 → 签收 → 逐管验收
                       ↓
               结果录入 → 结果审核
                       ↓
               报告核对 → 签发 → 交付

拒收、不符合项、补采和退回记录关联原申请及对应标本管。
```

申请号标识一份检验申请。管码标识一支实际标本管。同一申请可包含多支管，每支管分别保存标本类型、检验项目及采收状态。

结果保存、结果审核、报告签发和打印登记是不同操作。结果已保存不表示已审核，报告预览不表示已签发，打开 PDF 不表示纸张已经打印。

结果对外发送以正式签发版本为准。录入完成和审核通过不代表报告已发送。

## 2. 首次使用流程

1. 操作人员使用已分配账号登录，核对当前姓名和岗位。
2. 操作人员查看左侧菜单，确认本人负责的业务入口。
3. 接收人员核对患者、送检机构、科室、医生和开单项目。
4. 检验人员核对负责的专业组、工作单和结果队列。
5. 审核、报告人员核对待审核任务和报告记录。
6. 管理员核对主数据、岗位模板、专业组授权和已启用接口。

菜单缺失、专业组不可选或操作不可用时，由管理员核查当前账号授权。更换登录账号后重新查询，原账号的清单不作为新账号操作依据。

右上角帮助菜单中的“用户手册”打开本地手册网页。网页提供浏览器打印入口；发布版 PDF 通过同页下载入口打开。

中国演示版保留核心业务与外送。病理、细胞、免疫组化、实验笔记本、储存、运输和室间质评七类可选模块按当前配置关闭，直接打开这些已关闭模块的地址时显示未启用提示。其他研究专用菜单保持隐藏，部分兼容地址仍按原权限控制。已有资料继续保留；启用模块不代替岗位授权。

一级菜单可展开或收起。基础配置与系统管理的二级菜单直接进入对应工作页。患者档案、条码和逐管采收操作从申请与标本工作区或具体申请进入。

业务统计使用“报告类型”选择统计内容。检验工作单使用“查询分类”选择条件；分类切换不另建业务模块。

## 4. 默认岗位权限

配置入口：**系统管理 → 用户与权限 → 新增或编辑用户 → 默认岗位模板**。

岗位模板预填角色组合和菜单范围。管理员应用模板后核对当前表单，选择适用专业组并保存。应用模板本身不保存授权。模板所需角色缺失时，页面提示缺失项并保留现有权限。

| 岗位模板           | 默认业务域                   | 模板对应工作                                 |
| ------------------ | ---------------------------- | -------------------------------------------- |
| 申请与标本接收员   | 工作台、申请与标本、质量管理 | 患者建档、申请接收、采集签收、条码和不符合项 |
| 检验技师           | 工作台、检验                 | 指定专业组工作单与结果录入                   |
| 结果审核员         | 工作台、审核与报告、质量管理 | 指定专业组结果复核、退回和审核               |
| 报告发布员         | 工作台、审核与报告           | 指定专业组报告查询、生成和交付               |
| 质量负责人（常规） | 工作台、质量管理、审核与报告 | 不符合项、审核追踪、报表和审计查看           |
| 仪器数据操作员     | 工作台、检验、系统管理       | 仪器导入与指定专业组结果录入                 |
| 用户账号管理员     | 工作台、系统管理             | 账号、启停状态和角色分配                     |
| 系统管理员         | 工作台、基础配置、系统管理   | 主数据、接口和运行参数                       |
| 审计查看员         | 工作台、审计入口             | 授权审计记录的只读查询                       |

接收、录入、审核和报告角色按专业组分配。账号可具有多个角色，最终能力以保存后的实际授权为准。岗位模板不代替具体操作的权限核验。

同一专业组同时分配结果录入和结果审核角色时，页面显示职责冲突提示。兼岗范围、复核要求及禁止自审制度由医院确认；当前提示不等于全部业务入口已经强制禁止本人审核。

## 5. 申请与标本操作规程

### 5.1 患者档案

1. 接收人员进入患者档案，按中文姓名、患者编号、证件号、手机号或既往实验室编号查询。
2. 常用条件在列表上方。“高级搜索”进入姓名、出生日期、性别等进一步查询条件；返回列表保留原条件。
3. “新患者”打开新增弹窗。“查看/编辑”打开所选患者的资料弹窗，已有档案先以只读方式展示。
4. 操作人员核对姓名、性别、出生日期、患者编号、证件和联系方式。当前账号具备维护权限时点击“编辑”，再修改对应资料；无权限时保持只读。
5. 新患者按新增表单保存。维护已有档案时，点击“保存”，在“确认保存患者资料？”中核对本次内容，再确认保存；保存期间保持当前窗口，避免重复提交。
6. 保存成功后列表重新读取。取消或关闭返回原列表，保留查询与页码；有未保存内容时选择“继续编辑”或“关闭并放弃草稿”。

新增患者操作：新建患者弹窗中的“清除”清空本次未保存资料，窗口保持打开。配置的默认国籍恢复为默认值。操作人员重新填写后点击“保存”；“取消”关闭弹窗并返回原列表。保存或附件处理期间不能清空表单。

维护已有档案时，已有证件的修改、删除按独立操作即时保存，取消患者资料编辑不撤销已保存的证件变更。照片修改和新上传证件随患者资料一起保存，确认前仍为草稿。

保存失败时保留填写内容，按提示核对权限、档案变化或字段。已有档案维护的保存结果尚未确认时暂停编辑和再次保存，使用“重新核对已存档案”读取当前记录；关闭、刷新或重新打开不能代替原保存结果核对。资料一致不表示外部接口同步已完成，仍有待核实提示时交由授权管理员核查。

检验结果通过患者行中的“检验结果”进入。维护患者资料与查阅检验结果使用各自入口。

### 5.2 申请列表与手工建单

操作入口：**申请与标本 → 申请列表**。

1. 接收人员查询申请，核对患者、实验室编号、日期、优先级和标本准备状态。
2. “查看”打开已保存申请的只读详情，展示送检信息、各管标本和检验项目归属。
3. “返回列表”返回原条件和页码。缺失资料或历史状态不明时，详情显示对应说明。
4. “修改申请”重新核对当前申请及权限后进入既有修改页面。取消返回原列表条件。

详情中的外部标本编号保留原始标识；接收和验收使用临床标签上的管码。

新建检验申请使用完整工作区：

1. 接收人员检索并选择患者，无对应档案时使用“新患者”建立档案。
2. 接收人员核对患者身份，选择送检机构、科室或病区、申请医生和优先级。
3. 接收人员选择标本类型，添加组合项目或单项检验。
4. 接收人员核对管数、每管检验项目及标签安排，保存申请。
5. 申请首次保存后使用系统返回的申请号。外部已有编号按外部编号字段填写。

外送项目分别保存各自的机构、原因、送出日期和经办人。外送登记与申请一起保存；外部同步失败不撤销已保存的申请和外送登记。保存结果未确认时，先按申请号核对原申请及外送列表，避免重复建单；接口异常交由管理员核查。

修改已保存申请使用“标本与检验项目 → 送检信息”两步工作区：

1. 从申请列表的目标行进入“修改申请”，先核对患者、原实验室编号、每管标本和已有项目。
2. 在“标本与检验项目”核对目标管及项目。新增管分别选择标本类型和检验项目；资料不完整时先补齐，再继续。
3. 进入“送检信息”，核对原申请、接收日期时间以及送检资料。历史日期保留原值，原值为空时不自动填成当天。申请日期为必填项时，操作人员按原申请资料补录；资料未核实时保留空值，暂不保存。
4. 新的实验室编号为选填；留空保留原编号。原程序及附加问卷在折叠区只读查阅，自定义程序名称保留原配置。
5. 核对两步内容后保存。失败保留草稿；保存期间锁定输入和重复提交。本页“取消”或返回操作对未保存修改进行确认，再返回原列表条件。

附件上传、删除沿用独立的即时保存入口，本页取消不撤销已经保存的附件变更。标签打印仍使用原标签入口；此修改页不维护标签数量和结果通知设置。当前状态或权限不允许修改的已有管、项目保持只读，操作人员按页面原因处理。

查看已保存申请不进入新建流程。申请包含患者、送检资料及多管项目，修改申请仍为完整页面。

### 5.3 待接收电子申请

操作入口：**申请与标本 → 待接收电子申请**。

1. 页面默认读取当前权限范围内的待接收申请列表。
2. 接收人员按患者姓名、证件号或原机构检验号查询。
3. “展开查询条件”显示日期与处理状态，收起后保留已填写条件。
4. 接收人员核对所选行的患者、来源、项目及状态，再使用该行可用的核对或接收入口。
5. 返回电子申请列表时保留原条件及页码。

外部信息暂不可用时，页面保留本地已读取资料并显示告警。资料不完整、状态不符或无权限的行显示原因，接收按钮不可用。查询失败不表示没有申请。

当前演示电子申请的接收限制见第 14 节。列表中出现记录不表示该记录已经满足接收条件。

### 5.4 批量申请录入

批量申请录入先设置同批公共信息，再进入条码或逐条录入。

1. 在“1 接收信息”核对申请日期、时间及本批接收日期、时间。
2. 在“2 标本与检验项目”选择一种标本类型，再选择本批每份申请使用的组合或检验项目。
3. 在“3 条码与送检设置”选择“录入时生成”或“使用预印条码”，按本批需要选择录入时补充的送检机构、患者信息等字段，并填写送检资料。
4. 核对“开始前检查”中的标本与项目、条码方式、送检机构。待完成项补齐后点击“进入批量录入”，逐条核对编号及检验项目。
5. 使用“录入时生成”时，填写并核对本条患者和送检资料，点击“生成条码并保存”。等待编号生成完成；系统使用该编号保存本条申请。输入或修改资料本身不保存申请。
6. 使用“使用预印条码”时，扫描或填写本条编号。使用旁边的“生成”取得编号，也不会自动保存。核对患者、编号和检验项目后，点击“保存”。
7. 保存后等待系统读取同号申请，核对患者、送检资料、标本和检验项目。出现保存成功提示后，再使用标签打印区。编号已显示、预印标签已打开或保存请求已返回，都不能代替同号申请核对。
8. 在打印区核对申请号、标签类型和数量，再打开标签 PDF 或打印。录入时生成的申请完成本条操作后，点击“下一个标签”；原编号和打印回执清空，公共设置保留。处理下一条前重新核对患者和送检资料。

公共设置适用于当前批次。患者身份、条码来源和检验项目仍按每条记录核对。正式批量使用的编号与标签规则由医院确认。

出生日期未要求填写时可留空。已填写的日期按患者实际资料核对，不为通过校验填写虚构日期。编号或必填资料校验未通过时，系统显示对应错误；修正本条资料后重新保存。保存回执未收到或同号申请核对不一致时，保留当前资料和编号，暂停打印及下一条操作，先核查本条申请是否已保存，不重复提交。标签 PDF 已打开不表示标签纸已打印，实体打印效果仍需在实际设备上核对。

### 5.5 单管与多管申请

单管申请的项目使用同一支实际标本。多管申请在同一申请内形成两支或多支实际标本，每支管有独立管码与项目归属。

系统使用标本类型与检验项目的关联配置形成标本管。血清生化和全血血常规位于同一申请时，分别核对血清管与全血管。管数以保存后的真实标本记录为准。

| 核对内容         | 单管           | 多管                         |
| ---------------- | -------------- | ---------------------------- |
| 申请号           | 一份申请号     | 一份申请号                   |
| 标本管           | 一支管及其管码 | 每支管分别核对管码           |
| 检验项目         | 属于该管       | 分别属于对应管               |
| 采集、签收、验收 | 按该管登记     | 按各管分别登记               |
| 拒收与补采       | 关联原管       | 关联受影响管，核对其他管状态 |

容器帽色、采血顺序、最小量、同类型重复管、分杯和运输条件按医院确认的配置范围使用；系统不凭项目名称推定这些规则。

### 5.6 标本采集、签收与逐管验收

操作入口：**申请与标本 → 标本处理**，或具体申请中的采收步骤。

1. 接收人员扫描或输入管码，核对原申请号、患者、标本类型及检验项目。
2. 采集人员登记对应管的采集时间和人员。暂不签收时使用页面的仅采集操作。
3. 未签收标本登记签收；核对采集、签收记录与当前状态。
4. 合格管完成接收验收。不合格管选择拒收原因并提交。
5. 补采通过原管的关联补采入口建立，新管码与原管关系保留。
6. 操作完成后重新核对该管状态，按实际可用入口继续。

标本管理进入页面先显示最近标本，当前范围最多50项。按实验室编号查询可定位同一申请的真实标本管；清空条件并查询恢复最近列表。混合申请的最近列表不提供整份申请条码打印，精确定位一笔申请后才显示对应打印入口。

取消检验项目按目标管和项目逐项核对：

1. 展开目标管的检验项目，核对申请号、管码和项目，不以列表顺序代替项目身份。
2. 仅当前账号具有取消权限、管处于已登记且项目处于未开始或技术审核通过状态时，使用该项目可用的取消入口；不可用时先查看限制原因。
3. 在确认框中核对目标项目后确认取消。成功后保留该项目行，并显示已取消状态；失败不清空原记录。
4. 取消结果未确认时不重复提交。重新查询、刷新或重新打开仍须核对原结果；当前记录明确为已取消时再继续其他操作，仍未确认的结果交由管理员核查。

“已登记”只表示登记状态，不代表已采集、已签收或已验收。历史状态缺失或类别不符时显示待核对，操作人员按原记录核查。

多管申请逐管处理。一管拒收不代替其他管的验收，也不自动取消整份申请。已取消、历史停用或当前状态不允许操作的管显示原因。

### 5.7 标签与条码

操作人员预览标签，核对中文患者资料、申请号、管码、标本类型及项目。每张标签对应正确标本管。

条码预印在当前设置页完成：

1. 核对标签数量、送检单位、标本类型和检验项目；已填写的送检单位、标本及项目会用于本次预印标签。
2. 点击“预印标签”，在弹窗中加载本次条码 PDF，不在设置页下方继续堆叠查看器。
3. 关闭预览返回原设置页，标签数量、标本类型和检验项目选择保留；调整后再次预览。

预览窗口中的 PDF 用于核对版式。打印时选择正确打印机、纸张规格和标签预设。打印机输出及标签尺寸以实际样张核对。

## 6. 检验操作规程

### 6.1 结果录入

操作入口：**检验 → 待录入结果**。

1. 检验技师按实验室编号、专业组、日期及状态读取当前队列。
2. 检验技师选择标本，核对患者、原申请号、管码和检验项目。
3. 检验技师填写结果，核对单位、参考范围、异常标志和原始值。
4. 保存后读取当前行状态。已保存结果仍需进入审核环节。
5. 不可编辑的行查看受限说明，核对标本、项目、质控或权限原因。

页面任务数量与标本数量使用各自统计口径。加载失败、权限变化或状态未确认时，旧清单不作为继续保存的依据。

### 6.2 外送检验查询

操作入口：**检验 → 外送检验**。

1. 操作人员选择查询类别，按患者、实验室编号或日期与检验条件查询。
2. 日期、检验项目、专业组等条件通过展开查询填写。
3. 按所选类别核对患者候选或申请号，再读取外送列表。
4. 列表中核对外送机构、检验项目、发送日期与结果日期。
5. 查看或返回时保留原查询与分页。查询失败和无匹配记录分别显示。

申请保存后的外送登记不等同于外送机构接收回执。实际接收与结果回传另行核对。

外送机构、项目映射和回传方式按医院资料配置。演示库外送记录为空时展示空列表；不将空列表当作实际外送、回传或打印验收。

### 6.3 检验工作单

操作入口：**检验 → 检验工作单**。

1. 操作人员在“查询分类”中选择检验项目、组合项目、专业组或优先级。
2. 选择对应条件后读取待检验项目列表，核对申请原号、标本及真实项目。
3. 需要排除当前页某个任务时勾选该行“排除打印”。
4. 核对当前页清单后使用“打印当前页”。打印只包含当前页未排除的可打印项目。
5. 生成 PDF 后核对内容，再执行打印机操作。

换页、换条件及返回重新查询后，当前页排除选择清除。清单、权限或项目状态已变化时重新查询。生成工作单不修改检验任务状态，也不登记正式报告打印次数。

### 6.4 受限结果核对与采收入口

1. 检验技师在受限行点击“查看受限事实”，打开“受限结果核对”。
2. 核对申请原号、标本记录及检验任务，确认是当前受限管和项目。
3. 核对采集时间、签收时间、采集请求关联和接收验收决定。页面区分已记录、未记录、记录不一致和待核实。
4. 当前身份与权限允许时，使用“进入此管采收核对”进入原管处理入口。
5. 接收人员核对实际管及当前状态，按页面可用操作处理。当前账号只有读取权限时，保持只读。
6. 使用“返回结果清单”返回原队列，重新查询当前状态后继续结果录入。

记录存在不表示满足结果录入条件。进入采收入口不自动接收标本、不解除限制、不授权账号，也不切换其他标本管。

身份、权限或记录状态无法核实的情况下，页面显示原因并暂停对应入口。保存结果未确认时保留当前操作，核对原请求，不重复提交。

## 7. 审核与报告操作规程

### 7.1 结果审核

操作入口：**审核与报告 → 审核工作台**。

1. 审核员选择负责的专业组并查询待审核结果。
2. 审核员核对患者、原申请号、对应管、检验项目、结果、单位和参考范围。
3. 审核员核对异常标志、标本不符合项、质控限制及需要复核的记录。
4. 对可通过结果选择通过；对需退回结果选择退回并填写原因或备注。
5. 批量选择前核对实际清单和选择范围，再提交审核。
6. 提交后重新读取状态，按服务器确认结果继续。

审核页统计覆盖整次筛选时，以页面统计说明为准；当前已加载结果行的分页不等于全部任务已处理。受限说明与查看详情用于核对具体对象。

录入页在已确认保存且当前账号具有审核权限时提供审核入口。当前页仍有未完成录入或未确认保存时先处理原记录；入口不替代审核岗位授权。

### 7.2 患者检验报告

操作人员按患者或申请条件查询报告，核对姓名、身份资料、申请号、标本、检验结果和报告状态。患者记录中的检验结果入口用于查阅对应患者结果。

旧报告查询、正式报告文档和统计 PDF 使用各自操作入口。报告名称和模板以已配置内容为准，历史或外部原始文字不在查询时擅自改写。

### 7.3 正式检验报告

具有对应权限的报告人员在患者结果页面的“正式检验报告”区域操作：

1. 选择申请号和报告分组，建立分组报告文档。
2. 选择文档与报告版本，准备首次草稿；更正版填写更正原因。
3. 冻结报告内容，核对患者身份、结果、单位、参考范围和模板版本。
4. 打开冻结预览，核对本版 PDF。签发前的内容标记为“预览 — 尚未签发”。
5. 勾选已核对冻结内容与患者身份，填写当前账号密码，执行“签名并签发本版”。
6. 操作后使用“刷新并核对状态”，确认本版记录。

“查阅历史原件”用于读取存储原件。“登记当前报告打印”记录当前正式报告打印操作。打印登记与实体打印机输出分别核对。作废操作填写原因并执行该版的签名确认。

操作结果尚未确认时，先刷新读取已记录状态；未确认打印登记同时核对审计记录。完整签发、更正、作废、签章与真实打印的医院验收范围见第 14 节。

### 7.4 业务统计

操作入口：**审核与报告 → 业务统计**。

操作人员通过“报告类型”选择工作量、项目汇总、不符合项或审核超时等统计。检验工作量统计按以下顺序操作：

1. 操作人员选择“检验工作量统计”，核对专业组、申请优先级、接收时段和统计年度。
2. 点击“查询统计”，读取当前范围的工作量清单。
3. 核对检验项目、1—12 月及全年“检验量 / 标本量”，并核对页面显示的检验量和标本量合计。
4. 当前查询成功后，点击“生成可打印版本”，生成与已查询清单相同范围的打印版。

首次进入时打印按钮不可用。专业组、优先级、接收时段或年度变化后，旧清单清除，打印按钮再次不可用；重新查询后再核对与生成。查询失败与无统计结果分别显示。

专业组范围受当前报告权限限制。未选择某组可选条件时，仍按该组全部可用选项统计。项目汇总、不符合项及审核超时等报告按各自页面条件和生成入口操作，不视为全部统计报告已经提供相同网页清单。

### 7.5 正式报告对外发送

本候选版统一在正式报告签发后对外发送。报告草稿、冻结预览和仅完成审核的结果不作为正式报告发送。

1. 报告人员完成“签名并签发本版”后，使用“刷新并核对状态”，核对报告号、版本和签发状态。签发成功后，系统保存本版原件并登记发送任务。
2. 接口维护人员核对 FHIR 发送通道的配置和启用状态。已配置通道发送已签发的 PDF 原件；未配置通道时不发送，已保存的原件和任务保留。
3. 更正报告时填写更正原因，重新冻结、核对并签发新版本。新版本签发后，旧版未完成的发送任务关闭，新版登记更正发送任务。旧版原件和已确认回执保留。
4. 作废报告时核对当前版本，填写原因并完成签名确认。作废成功后，旧版未完成的发送任务关闭，并登记撤回任务。历史原件和已确认回执保留；本地登记撤回不代表接收系统已完成撤回。
5. 系统管理员在报告发送的“运行异常”中刷新台账，核对业务编号、任务类型和处理状态，并结合正式报告记录核对本次版本。发送结果未知时先核对原任务和接收端记录，未查明前不反复手工重试。

发送状态记录本次请求的处理进度，不等同于医院业务确认。模拟回执、人工登记回执和接收端实际确认分别核对；接收系统是否已收到并使用当前版本，以接收端核对结果为准。

当前 FHIR 通道发布正式 PDF 原件，不发布逐项结构化检验结果。需要逐项结果的接收系统另行核对字段、项目编码、患者身份和版本规则。系统内的患者结果查询、历史原件查阅、工作单和统计打印沿用各自入口。真实医院对接与接收端验收另行登记。

## 8. 质量管理

### 8.1 不符合项台账

操作入口：**质量管理 → 不符合项管理**。

页面默认展示当前权限范围内台账。操作人员按编号、标题、描述或实验室编号查询，再按状态、类别和严重程度缩小范围。

“登记不符合项”打开登记弹窗。五段内容依次为登记人与事件信息、分类与分级、事件详情、附件、关联标本或结果。

1. 操作人员填写事件日期和登记信息，选择已配置类别、类型与严重程度。
2. 填写事件标题、描述、处置资料和需要记录的备注。
3. 添加需要保存的附件，核对附件列表。
4. 按真实申请选择受影响标本或结果，完成关联后核对已关联清单。
5. 提交登记，按返回编号核对已保存事件。取消返回原查询及分页。

同一事件可关联不同申请下的标本或任务。取消关联只移除本次选择，不代表拒收或删除标本。附件与关联仍有未保存内容时，关闭窗口先确认草稿处理。

不符合项菜单设置：登记、查看和纠正措施入口同时受菜单开关与当前事件权限限制。关闭登记开关后不显示登记入口；关闭查看开关后保留已授权的台账查询，收起事件详情、附件和处理入口。纠正措施入口还需当前事件允许处理。切换账号或菜单资料无法核实时，重新读取当前菜单和台账后继续。启用开关不授予业务权限，也不解除标本或结果限制。

### 8.2 事件跟踪

当前台账提供事件确认、备注和指派入口。待处理事件的确认进入调查中；操作前核对当前事件、权限和版本。

事件发生变化时重新读取台账。登记保存结果未知时保留草稿、附件和原请求，使用“核对保存结果”读取回执；没有确认未保存前不再次登记。

在原纠正措施工作区，操作人员按事件编号查询并核对事件资料。

1. 选择“不符合项讨论日期”，点击“新增讨论日期”，确认日期已出现在上方列表。只选择日期不会加入本次保存内容。
2. 新增措施时填写措施内容、负责人、完成日期，并选择至少一种措施类型。暂不新增措施时整行留空；填写不完整时不能提交。
3. 措施行的“完成日期”记录单项措施的完成时间。“整改效果确认”区域的“完成日期”记录事件最终解决日期，两处分别填写和核对。
4. 核实整改效果后按实际情况选择“是”或“否”。选择“是”且措施资料完整或整行留空时，点击“提交”；选择“否”时不提交完成记录。
5. 确认保存提示，再按原事件编号查询，核对讨论日期、措施内容、负责人、类型、措施完成日期和最终解决日期。

保存失败时保留当前已填写内容，核对提示后修正草稿。保存结果不明确时先查询原事件，未核实前不重复提交。

原处置链的完整复核、关闭和医院制度仍列为独立验收范围。登记事件不自动解除相关检验结果的受限状态。

### 8.3 质量预警

操作人员查看已启用预警，核对项目、标本、规则和发生时间。阈值、复核、通知对象及闭环时限按医院确认资料配置。

### 8.4 仪器质控待处理

操作入口：**质量管理 → 仪器质控待处理**。具有 `Global Administrator`（全局管理员）或 `Lab Supervisor`（检验主管）实际授权的人员按仪器、项目及质控标本核对记录。

常规“质量负责人”岗位模板不自动包含上述授权。批号、仪器和用户权限由具有对应配置权限的人员维护；本页访问权限不扩大其他质控或批号配置页面的权限。

列表默认显示待处理记录，按状态查询并分页。每条记录保留原批号、水平、测定时间、读数、原始资料、处理原因和已创建的质控记录编号。数据已接收、质控记录已创建和质控规则合格分别核对。

1. 打开原记录，核对仪器、检验项目、质控标本号、批号、水平、测定时间和原始读数。
2. 未知批号、停用批号、同号歧义或批号与水平不一致时，先核对仪器原始资料，再在批次配置中维护正确资料。系统不将明确传入的未知批号归到另一批号。
3. 配置核实后，在同一条原记录中执行“重新处理”。处理使用已保存的原件，不编辑原批号或读数，不重发整包仪器数据。
4. 操作后读取同一条记录。显示“已入库”及质控记录编号后，本条导入异常关闭；继续核对质控规则评估和受限说明。“已入库”不表示质控合格或临床结果可放行。
5. 提示处理结果未知、超时或连接中断时，先刷新查回。已有质控记录编号时不重复创建；核对后仍未入库且页面允许操作时，再人工执行“核对后重新处理”。系统不自动重试。
6. 项目未映射、非数值、只读或更正记录仍按具体原因保留待核对；本页不改写原件或覆盖既有质控。历史记录缺少可信原件或入库关联时显示“历史待核对”，不能直接补处理。

同一原件重发按原件身份去重；不同测定时间、批号、水平或项目的质控不因数值相同而合并。明确更正或同一来源检测身份发生内容变化时保留新旧原件，等待人工核对。交班时跟踪尚未处理和结果未知的记录。

## 9. 基础配置

基础配置二级菜单直接进入列表。检验项目与标本类型的基础新增、编辑使用统一弹窗；复杂关联配置及已有项目名称维护从所选对象进入对应工作区。

| 菜单         | 维护内容                               | 操作核对                                       |
| ------------ | -------------------------------------- | ---------------------------------------------- |
| 检验项目     | 名称、报告名称、编码、专业组及适用标本 | 基础弹窗保存后核对列表；关联配置按同一项目进入 |
| 标本类型     | 名称、启用状态及相关定义               | 保存前核对名称与现有类型，返回保留条件和页码   |
| 组合项目     | 组合名称与所含检验项目                 | 核对每个项目、启用状态和标本归属               |
| 专业组       | 检验业务分组                           | 核对项目归属及人员授权范围                     |
| 检验规则     | 已开放规则定义与关联                   | 查询、编辑和保存后核对实际记录                 |
| 机构与科室   | 送检机构、科室或病区                   | 按对象维护，核对启用状态和机构归属             |
| 申请医生     | 医生与联系资料                         | 弹窗维护，核对医生身份及联系方式               |
| 标签模板     | 管码与标签预设                         | 使用测试标签核对纸张与内容                     |
| 报告发送配置 | 收件对象、条件与发送配置               | 保存后核对当前配置；外部目标另行联调           |

项目关联配置包括适用标本、结果定义、方法、参考区间、组合、编码、仪器及已启用规则。进入关联工作区时核对当前检验项目，返回目录后使用保留的筛选和页码。

检验项目新增与基础修改在目录弹窗中完成。新建时填写名称、报告名称、专业组和适用标本；新项目默认停用，保存后进入关联配置，完成结果定义等必要资料，再在关联工作区启用。启用后核对申请中可选项目。已有项目名称在基础信息中只读，名称及报告名称通过关联配置的“中文名称”维护。

旧新增地址进入同一弹窗，旧修改入口进入当前目录。保存成功后，提示中的关联配置入口指向刚保存的项目；取消和返回保持原专业组、搜索词与页码。

项目的字典结果按既有选项编号维护，完整名称、顺序、默认值和正常参考分别核对。报告范围上下限在参考区间中维护；批量修改前核对涉及项目及对应结果项，不能对应的项目不批量保存。

标本类型旧新增地址进入当前列表的新增弹窗。创建前等待完整列表读取，核对名称与停用记录，大小写或首尾空格差异不作为不同类型。保存后读取同一条记录，再返回原列表。

项目与标本关联工作区的标题和左侧当前对象摘要显示已确认名称。切换界面语言保留当前未保存内容；标题更新不代表草稿已经保存。更换账号或当前对象后重新读取，不沿用原账号草稿。

组合项目与专业组名称由管理员在各自列表维护：

1. 在目标行点击“编辑”，中文界面先维护“中文显示名称”。
2. 需要修改英文或法文名称时展开“其他语言名称”。缺少必填名称时先补齐，再保存。
3. 保存后核对原筛选和页码中的名称，重新打开可读取已保存资料。失败保留输入；提交期间不重复保存。

名称编辑不改变组合项目关联、专业组授权范围、排序或启停状态，这些内容使用各自配置入口。

多管使用前先维护标本类型、项目关联、组合项目及编号和标签预设，再核对单管、多管、部分拒收和关联补采场景。容器、采血量和运输规则不由通用岗位模板确定。

标本类型基础弹窗分别显示“中文显示名称”“内部标识名称”“英文名称”和“法文名称”。中文显示名称用于中文界面，内部标识名称用于系统匹配与权限模块；新增时分别填写，不用废弃处置说明替代名称。

已有标本类型的内部标识名称和英法名称保持只读，修改中文显示名称不覆盖这些原值。“废弃处置说明”在独立配置区维护，作为参考文本使用，不代替结构化处置规则。

配置保存失败时保留填写内容。列表重新读取失败不表示配置未保存，按页面状态核对原记录。

申请医生新增与编辑使用同一弹窗。新增结果未确认时，先按本次姓名等资料查找候选，再选择并核对实际记录；不能因列表暂未出现就重复新增。历史医生资料缺少有效身份时，由管理员核查原记录，不通过再次新增替代修改。

测量单位新增在当前主数据工作区弹窗完成。保存结果未知时，关闭重开仍保留当前页面的待核对状态，先读取确认记录。这些待核对状态不代替服务器回执；刷新页面后仍需核查原请求，不能据此认定未保存。

检验规则由系统管理员按名称、类型和状态查询。类型为“结果触发加做”或“计算结果”：

1. 使用“新增加做规则”“新增计算规则”或目标行“编辑”打开当前列表上的弹窗，核对所选标本、项目和规则内容。
2. 保存后核对该规则记录。启用、停用使用独立确认操作，编辑停用规则不等于启用。
3. 保存结果未确认时使用“核对保存结果”。新增未收到可确认编号时，该核对按钮不可用，先返回列表核查是否已创建，不重复新增。

报告发送由系统管理员通过“配置分类”进入“发送渠道”“报告分组”或“运行异常”。首次打开某类配置时读取该类内容；同一页面内切换后保留已打开分区的草稿和待核对状态。更换账号后重新读取：

1. 在发送渠道核对当前设置，按对接资料维护并保存；保存配置不表示外部目标已联通。
2. 只有明确显示“尚未配置报告分组”时，才使用“建立首次分组配置”。该按钮先建立当前页面草稿，填写代码、名称及项目后再点击“保存报告分组”；损坏、停用或读取失败不按未配置处理。
3. 渠道或分组保存结果未确认时，核对当前设置及审计记录，不重复提交。
4. 运行异常按状态筛选并使用“刷新台账”。页面统计只覆盖当前筛选已加载的消息，最多100条，不代表全部历史记录。
5. 人工关闭时填写“关闭原因”，再点击“确认关闭”；关闭后停止该消息重试。操作结果未确认时刷新并核对台账和审计记录，不重复操作。

规则阈值、分组方式、渠道启用及人工关闭制度按医院确认资料使用，不因页面提供入口而自动启用。

### 9.1 常用字典、编号规则、检验方案与流程参数

本节记录四个基础配置入口。维护岗位为系统管理员；用户账号管理员不因维护账号而取得这些配置权限。

“常用字典”进入结果字典管理列表。点击“添加”打开“新增字典项”弹窗；选中目标条目后，点击工具栏“修改”打开“编辑字典项”弹窗。保存后核对目标条目。

“编号规则”进入实验室编号管理工作区。核对“实验室编号类型”和前缀设置，点击“保存并启用”，在“启用新的编号规则？”确认框内核对并确认。编号规则使用该工作区维护。

“检验方案”进入“检验方案与申请表单”工作区。界面中的“程序”对应检验方案；“新建程序”建立方案，在“程序名称”“程序编码”“检测科室”和“问卷标识”等字段维护资料，再点击“保存程序”。切换未保存方案时先确认草稿处理。本入口仍使用工作区维护。

“流程参数”在同一页面通过“配置类别”选择站点信息、订单录入配置、患者录入配置、工作计划配置、结果录入配置、验证配置、打印报告配置、不符合配置或菜单声明配置。“搜索配置”按名称缩小列表。编辑弹窗中的“值”按参数类型填写，布尔值选择“是”或“否”：

1. 系统管理员选择配置类别，按名称查询目标参数，再核对当前页的参数名称与值。
2. 点击目标行“编辑”，在编辑弹窗内修改参数；先核对用途与生效范围，再保存。
3. 保存成功后重新读取当前类别列表。取消关闭弹窗并保留原参数。
4. 编辑窗口打开期间，先保存或取消当前编辑，再切换类别或使用页面内返回。
5. 保存期间参数不可修改，关闭、取消及重复提交不生效。保存失败后弹窗保留本次填写内容，核对错误提示后重试。

打印参数显示：打印报告配置中的页眉附加信息、左右侧标识、负责人姓名、署名、职称、签名图片、报告页码及机构名称使用中文名称和默认说明。搜索支持中文名称与原参数标识；编辑保留原参数标识和已填写的值。自定义说明和未知参数按原资料显示。

参数读取失败与空列表分别处理。保存结果未确认时先核对原记录，不重复提交。“界面标识与配色”和“检验通知配置”等低频页面按实际开放入口使用。

## 10. 系统管理

### 10.1 用户与权限

管理员在“用户与权限”维护账号、启用状态、岗位模板和专业组授权。新增使用弹窗；编辑时核对所选账号身份和现有角色。

岗位调整后核对保存结果和实际业务入口。账号的登录身份用于操作记录归属。医院账号分配、离岗停用和兼岗制度由医院确认。

### 10.2 操作日志

操作日志入口默认读取最近记录。常用业务编号查询位于列表上方，日期、业务对象、操作和用户等条件通过展开查询使用。

审计人员先查看列表，再按条件缩小范围。导出前核对条件和权限。查询失败、无记录和登录失效使用各自反馈。

### 10.3 外部接口与运行配置

管理员在已授权入口维护系统参数、外部接口、语言、日志及上线检查项。新增或编辑使用该工作页的弹窗或配置区，保存前核对对象。

接口地址、认证、项目映射和发送范围按对接资料填写。保存配置不代表真实接口已联通。停用、删除和其他危险操作在确认框中核对对象及影响范围。

“系统参数”为只读列表，按参数名称或显示值搜索，并按分类缩小范围。敏感值遮蔽显示，不在此页直接修改参数。每页可选20、50或100条；搜索或分类改变后从第一页核对结果。

“系统日志”进入页面直接显示实时日志，当前页面最多保留最新500行，与第10.2节的业务操作日志分别使用：

1. 使用“暂停”停止当前页面接收，使用“接收”重新开启。连接中断时按提示暂停后重新接收。
2. “清空显示”只清空当前页面的日志内容，不删除服务器日志文件或业务操作历史。
3. 需要调整运行日志时展开“日志级别设置”，核对日志级别和Logger名称，再点击“应用日志级别”。应用失败保留设置，按提示核查。

日志级别调整不用于改变业务审计内容和保留周期。

### 10.4 菜单配置

操作入口：**系统管理 → 菜单配置**。由系统管理员维护。

1. 在配置类别中选择“全局菜单配置”“患者菜单配置”“不符合菜单配置”“研究菜单配置”或“计费菜单配置”，核对当前类别及原有菜单。
2. 修改需要调整的启用状态，再保存。全局菜单保存时，在确认弹窗中核对调整内容并确认。
3. 保存后重新进入当前配置类别，核对状态。读取失败保留提示，未核实前不重复保存。
4. 未保存时切换类别或打开其他页面，选择“保留编辑”继续填写，或选择“放弃修改并继续”。提交期间等待原操作完成。
5. 使用浏览器返回或前进时，确认放弃修改后当前类别重新读取。页面提示“修改已放弃，请再次使用返回或前进”；再次使用原返回或前进继续操作。

患者、不符合和计费菜单保存期间，启用状态及计费地址暂时锁定。保存成功后显示返回状态；保存失败保留本次填写内容。浏览器恢复此前页面时重新读取菜单，已有未保存内容保留；读取失败按提示核对后再操作。

计费地址为空表示尚未配置对接。已填写地址使用 HTTP 或 HTTPS。保存菜单配置不表示计费系统已联通。

“岗位菜单”展示当前岗位的菜单分配。“菜单配置”维护原有菜单的启用状态。业务操作仍按账号权限判断，启用菜单不授予业务权限。用户账号管理员不因此取得菜单配置的维护权限。

患者菜单设置：患者菜单的维护开关控制患者档案管理入口；检验历史开关控制患者列表中的“检验结果”入口。普通申请中的患者选择与新建患者仍使用申请流程的权限，研究菜单的“新建患者”配置不作为普通新患者的开关。菜单关闭、读取失败或账号变更时，旧账号的入口不继续使用。

研究菜单配置按以下顺序操作：

1. 系统管理员选择“研究菜单配置”，等待12项配置完整读取。
2. 核对已启用数量。部分启用时，根项显示混合状态；勾选根项启用全部配置，取消勾选停用全部配置。
3. 使用“显示配置项”展开原有配置，再调整各项启用状态。展开或收起不提交修改。
4. 点击“提交”，保存后重新进入研究菜单配置，核对12项状态。读取失败或资料缺失时重新加载，不提交未完整读取的配置。

中国版继续隐藏研究专用业务入口；这组配置不授予岗位权限，也不代替普通申请和患者维护的业务入口。

### 10.5 通知发送

操作入口：**系统管理 → 通知发送**。系统管理员选择接收用户，填写通知内容并提交。等待站内保存回执，按通知编号和本次发送记录核对结果。站内通知保存与浏览器推送分别显示。

1. 显示“站内通知已保存。接收人尚未启用浏览器推送。”时，回执状态为 `NOT_SUBSCRIBED`。通知已存入系统，当前接收人没有浏览器推送订阅；不为补发推送重复提交相同通知。
2. 显示“站内通知已保存，浏览器推送未完成。请勿重复发送。”时，回执状态为 `FAILED`。站内保存已经完成，推送查询或发送未完成；按原通知记录核查推送问题，不再次创建相同通知。
3. 显示“站内通知已保存，推送服务已接受。接收设备送达尚未确认。”时，回执状态为 `ACCEPTED`。推送服务已接受请求，仍不能据此确认接收设备已收到或接收人已阅读。

只有站内保存回执有效时，页面才清空本次通知内容并记录发送结果。真正保存失败或回执无法核实时，页面保留内容并提示错误；先核对原请求和通知记录，不把错误提示当作已保存，也不反复点击发送。浏览器外部推送、接收设备送达及医院通知闭环另行验收。

## 11. 通用页面操作

### 11.1 列表与查询

列表默认读取页面约定范围，受当前授权限制。高级条件通过展开或收起使用。重新查询后核对当前页、记录数和条件，避免把旧清单用于新条件。

查询无结果时核对日期、状态、专业组与关键字。读取失败按页面重试，不把异常当作零记录。

### 11.2 返回与弹窗

患者新增维护、主数据基础编辑和不符合项登记使用统一主题弹窗。申请及复杂关联配置保留完整工作区。

返回列表使用页面按钮，保留对应页面已支持的条件和页码。取消或关闭不提交当前草稿；页面注明即时保存的独立操作按其实际记录核对。

未保存内容关闭时选择继续填写或放弃草稿。保存中或保存结果未知时，先核对原操作。

通用配置弹窗提交期间保持打开，关闭、取消与重复保存暂时停用。保存成功后返回列表并读取记录；保存失败保留字段和已选图片，按提示核对后再提交。

### 11.3 操作按钮与反馈

保存、确认等主要操作使用主题色按钮；取消和返回为次要操作；删除等危险操作使用红色确认。灰色或禁用按钮表示当前条件不满足，原因见附近提示。

按钮颜色不代表保存完成。成功提示与重新读取记录用于核对结果；失败和未确认提示按各自处理入口继续。

### 11.4 页面与打印

加载失败使用“重新加载页面”或当前查询重试。再次失败时记录页面、时间、编号及步骤，由管理员核查。

手册浏览器打印调用系统打印窗口。窗口未显示时使用浏览器菜单中的打印。PDF 下载与网页打印各有入口；版本、文件和纸张内容分别核对。

## 12. 异常处置

| 现象                 | 处理                                                         |
| -------------------- | ------------------------------------------------------------ |
| 菜单不可见或无专业组 | 管理员核对账号、角色、专业组与模块；用户重新登录后查询       |
| 无可选项目或标本     | 核对项目启用状态、适用标本与专业组配置                       |
| 多管中一管拒收       | 核对原管记录和拒收原因，按原管建立补采，分别核对其他管       |
| 扫码无响应           | 核对输入焦点与扫描枪回车；手工输入同一管码核查               |
| 查询失败             | 保留条件并重试；不按空列表继续操作                           |
| 保存结果未知         | 保留草稿和原请求，读取回执或记录；不重复提交                 |
| 结果受限             | 查看当前行原因，核对原申请、原管、项目和权限；不自行重置状态 |
| 报告操作未确认       | 刷新报告记录，核对版号；打印登记同时核对审计                 |
| 打印内容或尺寸异常   | 核对模板、纸张、缩放与打印机，使用测试样张校准               |
