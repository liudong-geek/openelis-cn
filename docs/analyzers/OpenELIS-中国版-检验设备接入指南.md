# OpenELIS 中国版检验设备接入指南

## 1. 接入结论

检验设备不能只在页面中填写 IP 地址和端口后直接使用。完整接入由两部分组成：

1. **分析仪桥接服务**：负责从网口、串口或结果文件接收设备数据，并可靠地转发给 OpenELIS。
2. **OpenELIS 设备驱动**：负责识别设备报文、提取实验室编号和检验结果、执行项目映射并写入待审核结果。

两部分都准备完成后，才可在“系统管理 → 分析仪”中建立设备、测试连接和配置项目映射。

当前本地环境启动日志显示可用设备驱动数量为 0。因此当前页面只能用于准备配置，尚不能声称已经具备真实设备接入能力。

## 2. 先向设备厂家取得资料

开始开发前，必须取得以下资料：

- 设备厂家、型号、软件版本和序列号；
- 接口说明书及通信协议版本；
- 通信方式：网口、串口或结果文件；
- 设备作为客户端还是服务端；
- IP 地址、端口或串口参数；
- 双向或单向通信要求；
- 至少三份已脱敏的真实报文或结果文件；
- 项目代码、单位、异常标志、定性结果代码对照表；
- 实验室编号在报文中的字段位置；
- 查询申请、接收任务和回传确认的握手机制。

没有真实接口说明书和样例报文时，不应凭设备名称猜测协议。

## 3. 选择接入方式

| 设备输出能力 | 推荐路径 | 适用场景 |
| --- | --- | --- |
| 网络 ASTM | 设备 → 桥接服务 ASTM 监听端口 → OpenELIS | 血球、凝血等常见分析仪 |
| 网络 HL7 v2 | 设备 → 桥接服务 MLLP 监听端口 → OpenELIS | 生化、免疫、分子等支持 HL7 的设备 |
| RS-232/RS-485 串口 | 设备 → 串口服务器或本机串口 → 桥接服务 → OpenELIS | 只有串口输出的旧设备 |
| CSV、TXT、Excel 文件 | 设备导出目录 → 桥接服务文件监控 → OpenELIS | 只能导出结果文件的设备 |
| 厂家私有协议 | 开发专用驱动或由厂家中间件转换为 ASTM/HL7 | 无标准接口或字段含义特殊的设备 |

文件接入时，桥接服务负责监控、稳定性检查、归档、失败目录和重试；OpenELIS 不应与桥接服务同时监控同一目录。

## 4. 系统配置顺序

1. 部署分析仪桥接服务，并设置独立强密码；只开放实际使用的监听端口。
2. 安装与设备型号匹配的 OpenELIS 驱动；没有专用驱动时，评估通用 ASTM、通用 HL7 或通用文件驱动。
3. 在“系统管理 → 分析仪”新建设备，选择接口模板和消息协议。
4. 填写网络地址、端口或文件接收目录，执行连接测试。
5. 配置设备项目代码与 LIS 检验项目的映射；同时核对单位、结果类型和小数位。
6. 将设备状态设为“验证中”，使用模拟申请和质控样本完成联调。
7. 验证通过并由检验科、设备工程师和信息科共同签字后，再切换为正式运行。

## 5. 上线验收清单

### 正常流程

- 设备能收到正确的实验室编号和检验项目；
- 正常数值结果进入正确患者、标本和检验项目；
- 单位、小数位、参考区间和异常标志正确；
- 定性结果不会被错误标为“正常”；
- 结果先进入待录入或待审核状态，不直接越过审核签发；
- 双向设备的查询、应答、确认和重试符合厂家协议。

### 异常流程

- 未知实验室编号进入异常队列，不新建错误患者；
- 未映射项目、无效数值、缺少单位和重复报文均有中文提示；
- 断网、超时、设备重启和桥接服务重启后不会丢失或重复写入结果；
- 同一报文重复发送具有幂等保护；
- 文件写入未完成时不会提前读取；失败文件进入隔离目录；
- 未授权来源不能向结果入口注入数据。

### 业务验收

- 正常、异常、危急、定性和超线性范围结果各至少验证一例；
- 同一标本多项目、多次复查和结果更正链路可追溯；
- 设备结果、人工修改、审核和报告签发均有操作日志；
- 两个实验室单元之间不能互看或写入对方结果；
- 连续运行和批量数据测试达到医院约定的吞吐量与稳定性要求。

## 6. 安全与部署要求

- 不使用桥接服务默认账号或默认密码；
- 监听端口仅绑定到检验设备网段，不直接暴露到互联网；
- OpenELIS 与桥接服务之间使用受信任的内部网络和身份认证；
- 配置文件中的密码通过环境变量或密钥文件注入，不提交到代码仓库；
- 原始报文、失败队列和日志按医院数据保留制度管理，并避免记录完整患者敏感信息；
- 正式接入前完成备份恢复、故障切换和接口停用演练。

## 7. 每台设备的交付物

每台设备应形成独立交付包，至少包含：

- 接口说明书和设备信息表；
- 脱敏报文或结果文件样例；
- 通信参数和网络拓扑；
- 项目、单位、结果代码映射表；
- 驱动和桥接服务版本；
- 正常与异常测试记录；
- 上线、回退和停用方案；
- 检验科、信息科、厂家三方验收签字。
