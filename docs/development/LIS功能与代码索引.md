# LIS 功能、代码与验证定位索引

日期：2026-10-14。用途：按功能找到真实入口及最小回归范围。功能验收和部署版本见六批优化验收记录。

路径均相对本仓库。`F` 指 `frontend/src/components/`；`J` 指 `src/main/java/org/openelisglobal/`；`T` 指 `src/test/java/org/openelisglobal/`。表内省略的文件扩展名通过同名文件定位。前端组件与单测在 F 下，Java 服务与测试分别在 J、T 下；组件目录外的页面单独写出仓库相对路径。

当前入口由 `frontend/src/App.jsx`、`admin/Admin.jsx` 和 `admin/adminNavigation.js` 定义；字面路由包含别名、详情及关闭扩展，不能当作独立功能数量。验证和发布见[开发与验收](LIS开发与验收.md)及[六批记录](../qa/China-LIS-six-batch-optimization-2026-10-13.md)。

## 日常验证入口

在仓库 `frontend` 目录运行：

```sh
npm run test:feature -- src/components/admin/ProviderMenu/ProviderMenu.test.jsx
npm run check-format:files -- src/components/admin/ProviderMenu/ProviderMenu.tsx
npm run format:files -- src/components/admin/ProviderMenu/ProviderMenu.tsx
```

`test:feature` 必须给真实存在的测试文件，可同时列多个；不接受目录、通配符、仓库外路径或附加运行器参数。普通测试复用现有 Vitest、最多两个工作进程；`NceCalendar.locale.test.jsx` 自动使用真实 NCE 日历配置，`CustomDatePicker.test.jsx` 自动检查普通配置与患者日历配置。不能用这个入口替代整批 `check:delivery` 门禁。

下表“局部验证”列中的前端测试路径相对 F；在上述命令后使用时加上 `src/components/` 前缀。同列 `.java` 文件相对 T，不能传给前端命令。涉及 Java 保存、权限、事务或 SQL 变动，再按该批已配置的离线 Java 测试环境运行这些 Java 测试；不要把需要数据库的集成测试当成纯前端单测，或临时另建通用运行框架。

## 关闭扩展与兼容入口

`frontend/src/config.json` 当前 `navigationProfile=china`，`pathology`、`immunohistochemistry`、`cytology`、`notebook`、`storage`、`shipment`、`eqa` 全为 false。对应实现保留在 `pathology/`、`immunohistochemistry/`、`cytology/`、`notebook/`、`storage/`、`coldStorage/`、`shipment/`、`eqa/`。`layout/taskFocusedMenu.js` 另隐藏 GenericSample、研究/项目专用菜单、旧独立 Aliquot 等入口。`inventory/`、StudyReports 与 genericProgram 保持原有路由行为，没有纳入这七项关闭开关。

这些是关闭或兼容能力，不是本轮认定的死代码。关闭菜单不等于后端权限拒绝；直接 URL、按需加载与权限仍由 App 路由及既有守卫控制。修改模块开关时检查 `layout/taskFocusedMenu` 的相应测试、App 认证路由测试和目标模块权限测试；不能只看菜单消失。`/program` 管理配置与被隐藏的 `genericProgram` 业务入口也不是同一页。

## 旧链路退役边界

旧新增、修改入口已转到当前目录与弹窗，保留 `LegacyCatalogRedirect` 及旧 URL。无运行消费者的 `TestModifyFilters`、`CustomShowGuide`、`CustomTestDataDisplay`、`TestFormData`、`TestStepForm`、`testStepDictionaryMatching` 及只服务该 helper 的测试已退役。逐项替代与保留范围见[历史链路清单](LIS历史链路保留与退役.md)。
