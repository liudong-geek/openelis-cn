# 中文三甲医院合成展示库

本地展示环境使用虚构机构“华东医学中心附属医院（演示）”。患者、医生、科室、申请号、标本号、联系方式、检验结果和报告状态均为合成数据，不对应真实医院或真实个人，不用于临床诊疗。

## 配置依据

展示库按公开国家规范组织业务场景，不复制任何医院内部制度：

- 国家卫生健康委《三级医院评审标准（2025年版）》：三级综合医院功能定位、科室设置、质量安全和数据监测要求。
- 《医疗机构临床实验室管理办法》：临床实验室按安全、准确、及时、有效、经济、便民和保护患者隐私的原则开展工作。
- CNAS-CL02:2023《医学实验室质量和能力认可准则》：等同采用 ISO 15189:2022，覆盖医学实验室质量和能力要求。
- WS/T 496—2017《临床实验室质量指标》：检验前、中、后过程质量指标。
- WS/T 616—2018《临床实验室定量检验结果的自动审核》：审核规则、差值检查、验证和发布管理。
- WS/T 641—2018《临床检验定量测定室内质量控制》：室内质量控制设计、运行和数据管理。

院方岗位授权、参考区间、危急值阈值、自动审核规则、仪器映射和报告签章必须在真实医院实施时重新审批。本展示库只提供流程数据，不把演示参数作为院方制度。

## 默认展示路径

1. 患者档案管理打开后显示中文患者列表，可按姓名、门诊号和演示证件号查询。
2. 待接收电子申请默认显示 8 条合成 HIS 申请，其中包含常规和急诊优先级。
3. 标本管理显示 48 份申请和 57 支标本管；申请号尾号 `00005`、`00010` 等为双管申请。
4. 结果录入显示 32 个待检验任务。
5. 审核工作台显示 24 个待审核任务。
6. 历史结果与报告查询包含 36 个已审核任务，其中 12 个任务（6 份申请）在当日完成。
7. 工作量统计同时包含当日完成量和跨月份趋势。

## 安全加载

加载器只接受 Compose 项目 `openelis-cn-e2e`，并同时校验数据库容器标签、服务名和 `e2e-db-data` 卷标签。SQL 仅接受没有患者和申请的全新基础库；任一条件不满足时立即停止。

```sh
OPENELIS_E2E_COMPOSE_PROJECT=openelis-cn-e2e \
OPENELIS_E2E_DB_CONTAINER=openelis-cn-e2e-database \
  ./scripts/load-cn-showcase-data.sh \
    -f build.docker-compose.yml \
    -f docker-compose.e2e.yml \
    -f docker-compose.demo.yml
```

登录地址为 `http://127.0.0.1:18080/login`。本地展示管理员为 `admin`。口令沿用本地开发环境配置，展示部署前必须按部署制度更换。
