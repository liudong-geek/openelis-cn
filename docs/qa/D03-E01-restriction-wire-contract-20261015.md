## 现象与修复边界

隔离 a11 的结果行 4／标本 4／项目 13 查询返回 HTTP 200，身份正确，但实际 JSON 省略接收日期、验收记录及处理入口说明中的五个必需空字段。前端严格解析因此拒绝展示。
