## 已修复

- 用户编辑、机构与科室编辑使用当前列表弹窗；保留查询和分页。用户保存成功正确调用父列表刷新，解决新增弹窗保存后仍跳整页的问题。
- 组合项目、专业组按当前行 ID 打开名称编辑，不再进入另一份目录重复选记录。旧接口只支持英文和法语名称，窗口明确标注维护范围，不将中文名称维护计为完成。
- 申请医生保存、停用后原位刷新；标签模板和语言管理使用统一弹窗、按钮、错误反馈及关闭行为。
- 保存期间禁止重复提交、关闭和继续修改字段；失败恢复操作并保留输入。修复 Carbon Esc 监听捕获旧状态以及标签 ComposedModal 隐藏底层编辑器的问题。
- 长表单正文独立滚动，动作栏保持可见；修正卡片被压缩和窄屏取消按钮裁切。保存/取消采用统一主题及 40px 高度，启用开关与数字输入使用同一主题。
- 中国版原“菜单权限”改为“岗位菜单”，复用实际侧栏适配器展示当前账号及现有九类岗位模板；授权仍从“用户与权限”分配。预览不修改角色或数据范围。全球模式继续保留原菜单配置。
- 日志设置按 HTTP 状态判断结果，避免请求失败误报成功。外部接口面包屑归入系统管理。
- 批量申请日期/时间不再互相覆盖；电子申请列表和筛选共用中文状态、优先级，原业务码及已接收禁用条件保持不变。
