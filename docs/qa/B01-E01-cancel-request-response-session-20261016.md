# B-01／E-01：取消标本任务响应的会话边界

## 问题与范围

A20 单次创建任务返回 201，取消 PUT 返回 500。响应明确为 TypeOfSample 延迟代理已无会话。随后独立 API／数据库只读核对确认原任务已处于 CANCELLED，未关联物理管；取消写入已经生效，原创建及取消均未重放。

基准为 cede12444c3fed2aa086758307640d1ae953602a；实际运行产品来源为 538767ab6999d51ca15a50478ed8e3b96fd0002a。此修复未部署，不能将旧版本的完整矩阵作为新产品版本通过。

## 修复

取消服务保持原事务、REQUESTED 状态门禁和一次 update。服务接收 update 返回的受管实体，在事务内复用现有 initializeLazyAssociations，返回该取消任务。控制器使用该返回值构造 DTO，取消原事务外再次 get。未扩大通用 get，未添加控制器事务或全局 EAGER，未修改授权、字段、审计和状态规则。

唯一生产调用者为取消 REST 控制器。现有服务测试忽略返回值，保持兼容；控制器成功测试仅将 void mock 改为返回同一取消实体，原状态码与回执断言全部保留。列表及完成采集已有服务内关联初始化，不在本次范围。
