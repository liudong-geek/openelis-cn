# 结果保存的实管生命周期准入：限定验收

日期：2026-09-14。基线：`0975367a0`。定位：当前“逐管验收结论与结果录入准入”主批的后台前置，不是该主批或全流程完成。

## 发现的问题与本批修复

现有 FHIR 标本取消入口可将实际 `SampleItem` 标记为取消、拒收，但对应 Analysis 仍可能保留待检状态。仅靠待录入列表筛选、前端按钮或已有 Analysis/报告状态检查，不能阻止直接保存结果。共享 `LogbookPersistServiceImpl.persistDataSet` 原先在无实管准入校验时就写入 Note 等数据。

本批在现有共享持久化事务内、第一笔写入前增加实管准入保护，并在业务更新后及提交前再次核对：

- 收集修改分析、新增/修改/删除结果、转诊及返回结果对应的实际管，核对分析—项目—实管—申请的真实 ID 关联。纯 ResultSet 修改和多管操作不能绕开；合法新转诊的空返回结果占位保留。
- 复用既有 SampleItem 的状态、rejected、voided；仅已配置的 Entered 生命周期且两个持久标志明确为 false 才通过这道基础检查。拒收、取消、处置、作废、缺失、未知状态或归属矛盾均阻断，不修改旧状态或拒收原因。
- 按实管、再分析的数字 ID 稳定顺序请求写锁；标量读取使用 MANUAL flush，并同时核对锁返回的真实会话实体，防止已在会话取消但尚未刷库的变化被旧标量掩盖。未调用 refresh、clear 或提前 flush。
- 所有目标先验证再写；晚发生的生命周期/归属变化或目标集合变化触发事务异常。正常检验推进 Analysis 状态、父申请状态不被误认为实管变更。
- 状态 ID 来源为原 StatusService 的初始化配置映射，正常查询为内存读取，不在该检查中初始化字典或查询业务库。

**这一基础保护只说明“未处于不可写生命周期”，不代表已逐管验收合格。** `rejected=false`、签收时间、旧整单布尔及 `MATCHED_CONFIRMATION` 均不是临床验收证明。历史 rejectReasonId 存在不同来源，保持原值，不重新解释。没有新增平行验收表、数据库迁移或临床规则。
