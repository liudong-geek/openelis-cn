# O02 合成数据性能和稳定性基线：限定验收

日期：2026-09-17。

## 本批交付

- 新增默认不执行的本机合成基线工具，负载目标固定为本机登录入口和专用临时数据库。
- HTTP 记录成功率、吞吐量、P50/P95/P99和最大延迟，零错误且P95不超过2秒才通过。
- PostgreSQL 使用`pgbench` scale 1生成10万条合成账户数据，记录事务数、失败数、平均延迟和TPS。
- 运行前后检查数据库、应用、代理健康状态并记录容器资源快照。
- 临时数据库只能使用`openelis_o02_perf_`前缀，完成后强制清理；任何清理失败都使演练失败。

## 验收边界

- 不登录业务账号，不读取或写入患者、申请、结果、报告、HIS或仪器数据。
- 登录入口和`pgbench`结果只作为当前本机环境的基础设施基线，不能替代业务查询、保存、报告、接口和设备的真实峰值测试。
- 未收到医院日量、峰值并发、脱敏场景和签字指标前，不承诺生产容量或长稳结论。
