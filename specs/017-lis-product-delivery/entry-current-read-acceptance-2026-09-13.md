# 保存核对：当前申请与逐管事实读回（限定验收）

日期：2026-09-13。接续 v3 当前主批；不另建回执体系或扩张菜单。

## 业务结果

新增 `GET /rest/SamplePatientEntry/submissions/{submissionId}/current`，在既有专用恢复事务内核对原提交者、历史回执、当前申请、患者关联、全部逻辑管、全部物理管及其实际检验项目。返回历史回执与只读当前事实两部分；旧历史查询行为不变。

- 不把历史 REQUESTED 当作现在未采集。当前 REQUESTED、COLLECTED、CANCELLED 独立返回；实管作废、拒收及 Analysis 状态不筛除、不推导为可继续写入。
- 仅按真实请求 ID 与显式 sampleItem ID 绑定，核对申请、类型、重复身份；同类型多管、同项目多条分析、实际数量与申请量不同均可保留。
- COLLECTED 的请求项目必须存在于其绑定实管的分析集合；允许额外/反射项目，但全部纳入授权。缺失原请求、关联不一致或部分读取失败不能返回部分成功。
- 原回执、全部当前请求（含取消）、全部实际分析项目取权限并集；读回前后复核操作人，沿用提交前身份复核。无权返回中文 403，未知失败中文 503，不返回底层异常或患者片段，成功/失败均禁止缓存。
- 额外未关联实管或分装子管返回明确 409“暂不支持自动恢复”，不称数据库损坏，不丢弃记录或自动重建。
- 追加管可以有相同显示排序，按排序＋真实 ID 稳定展示；不同身份不能因同排序被误拒绝。患者生日为日期字符串，不转成前一天 UTC 时间；事件时间仍为带时区时间戳。
- 环境申请允许零条患者关联或一条既有空患者关联；临床申请要求唯一、存在且与原保存患者一致。变更患者/编号/业务域不自动切换上下文。

返回 `current.readOnly=true`，没有 `canCollect` 或写入令牌。本批没有清除浏览器核对标记、恢复编辑、自动回填或继续采集；后续必须明确核对采用，写入口仍独立检查身份、权限及当前状态。
