# 首次整单保存：前端接入限定验收

日期：2026-09-13；对应唯一计划 v3 的 AC08 / AC14 / AC18 子集。父版本 `739551c6c`；后台合同已在 `c8e6e2e17`。本批不是发布候选，不更新本地 18080。

## 本批业务结果

- 新申请一次提交患者、申请信息、全部逻辑标本和申请级标签；保留程序问卷。浏览器生成唯一保存标识并冻结完整 JSON 原文及摘要；不再在首次保存后普通查号、逐管追加。
- 只有保存标识、原文摘要、患者、申请、每管身份/数量/项目/组合/状态及标签全部一致的正式回执才能显示成功、继续采集。HTTP 200、普通申请查询和不完整回执均不能代替确认。
- 保存草稿后，当前工作区同一会话、同一申请、内容未变的“继续”复用已确认结果，避免再次建管。室间质评仅允许原活动操作已经验真的服务器患者映射。
- 发送前摘要挂起在 10 秒内报未保存；迟到摘要不派发。发送后超时、不明/矛盾错误及权限/冲突响应保留未知状态。原命令在工作区私有内存中保留；界面只向同一登录会话显示不含患者信息的保存核对码。
- 明确新建初始化为 `modified:false`；不能仅凭 `modified:true` 将没有持久身份的草稿送入旧编辑写链。已有身份不一致时在发送前拒绝。
- 标签输入采用真实组件及后台的 `order_cells` / `preset_id`，回执采用 `presetId`。拒绝会被后台忽略的别名，零量、重复预设、数量与缺失回执分别核验。已填写患者或选择室间质评时不能静默切为环境标本，页面说明保留/清除资料或另建申请的选择。
