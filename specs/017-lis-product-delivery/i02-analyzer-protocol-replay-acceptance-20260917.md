# I02 仪器协议重放、映射与模拟验证

## 交付边界

本批提供管理员使用的只读协议重放能力，用于在真实仪器和医院接口资料尚未到位时验证映射配置。支持 ASTM LIS2-A2、HL7 v2 ORU 和自动识别。重放不会写入患者、标本、检验结果、仪器消息队列或错误队列。

FILE 协议仍由 Bridge 负责文件监听和传输；本批未在 OpenELIS 内增加目录轮询器。

## 验收条件

- 管理员可从分析仪字段映射页打开“协议重放与映射测试”。
- 可选择 ASTM、HL7 或自动识别，并可载入不含真实患者资料的合成示例。
- 服务端按分析仪字段上已配置的协议位置提取值，而不是用显示名称猜测字段。
- ASTM 支持位置引用（如 `R|3`）和带识别前缀的引用（如 `R|1|^^^GLU`）。
- HL7 支持标准段位引用（如 `OBX-5`）；旧配置中的竖线写法也可读取。
- 响应返回协议、SHA-256 报文指纹、解析数、应用映射数、未映射数、警告/错误数和 `clinicalWrites=0`。
- 结果预览使用当前启用的映射和插件配置快照，不激活映射、不触发重处理。
- 旧客户端仍可发送 `astmMessage`；新客户端统一发送 `message` 与 `protocol`。
- 空报文、超过 10KB 的报文和不支持的协议被拒绝或返回明确错误。

## 模拟数据

内置 ASTM 生化结果和 HL7 ORU 结果各一份，只使用 `SIM-*` 标识。它们用于验证界面流程和协议识别，不代表任何厂商私有协议已经完成现场认证。

## 现场资料到位后的复验

每种实际仪器仍需补充脱敏原始报文、厂商协议版本、字段说明、字符编码、传输帧规则和至少一组已知预期结果。现场复验通过后方可启用结果写入链路。
